What we check

The mistakes that actually get teams breached

Automated pattern scanning across your code, configs and CI, followed by a manual review of every lead.

  • Code injection & eval

    Dynamic evaluation of input: eval, new Function, unsafe templates.

  • Shell injection

    User data flowing into exec, system or shell=True.

  • Hard-coded secrets

    API keys, passwords and tokens committed to the repo.

  • Weak crypto

    MD5/SHA-1 for security, insecure randomness, outdated ciphers.

  • SQL / NoSQL injection

    String-built queries and user input in Mongo $where.

  • Disabled TLS & insecure cookies

    Certificate checks turned off, cookies without Secure/HttpOnly.

  • Privileged containers

    Docker/Compose/K8s configs running as root or privileged.

  • Unpinned CI actions

    GitHub Actions referenced by mutable tag instead of commit SHA.

  • Network calls without timeouts

    HTTP requests that can hang workers forever.

Languages & files: JavaScript/TypeScript, Python, Go, Rust, Solidity, shell, YAML and Dockerfiles.

FAQ

Honest answers

What you get, what you don't, and how payment works.

Is this a formal audit?

No. RepoGuard AI is a lightweight, AI-assisted review with manual verification of findings. It is not a formal security audit or certification, and it can't guarantee your code is free of vulnerabilities. It's a fast, affordable way to catch common, high-impact mistakes.

What does "manually verified" mean?

The scanner produces leads. Each lead is reviewed: false positives are dismissed, real issues are confirmed and explained, and each one gets a concrete fix suggestion. You get the confirmed list, not a raw dump.

Can you review private repos?

Yes. In your request, tell us how to get read access. For private repos the report is sent privately by email instead of being posted in the public issue. Fix pull requests are offered for public repos.

Why pay in USDC?

USDC is a dollar-pegged stablecoin, so $79 is exactly 79 USDC — no volatility. Payment on Base is fast with low fees, works across borders, and the transaction hash gives both sides a clear receipt. You only pay after we've confirmed scope.

How fast will I get the report?

Within 3 business days of payment. If we can't deliver, you get a full refund to the sending address.

Which languages do you support?

JavaScript/TypeScript, Python, Go, Rust, Solidity, shell scripts, YAML (including GitHub Actions) and Dockerfiles. If your stack is different, open a request and we'll tell you honestly whether we can help before you pay.
